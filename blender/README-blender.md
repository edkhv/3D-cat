# Чёрный котик (процедурная 3D-модель)

Всё построено скриптом, без внешних ассетов. Модель собрана прямо в вашей запущенной
Blender-сессии через MCP-мост (Blender MCP addon + `blender-mcp` в режиме HTTP).

## Файлы
| файл | что это |
|---|---|
| `build_cat.py` | генератор: мета-болл анатомия → меш, уши, глаза, нос, усы, шерсть (particle hair), свет, камеры |
| `build_cat_live.py` | обёртка для запуска внутри живой сессии Blender (через MCP) |
| `render_final.py` | финальный рендер 4 ракурсов из сохранённого `black_cat.blend` |
| `black_cat.blend` | готовая сцена (модель + свет + 4 «камеры-ракурса» в объекте `Cam`) |
| `renders/*.png` | рендеры 1200×1500, Cycles, 420 сэмплов, AgX |

## Как пересобрать
```bash
# head-less, с рендерами
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --python build_cat.py -- --final

# быстро, только модель, без рендера
... --python build_cat.py -- --quick --no-render

# внутри открытого Blender (Python-консоль)
import os, runpy
os.environ['CAT_LIVE']='1'; os.environ['CAT_NO_RENDER']='1'
runpy.run_path('/Users/edm/PI/3D/cat/build_cat.py', run_name='__main__')
```

## Что внутри модели
* **Тело** — мета-боллы (BALL по цепочкам позвоночник/лапы/хвост, негативные шары для глазниц),
  конвертация в меш (`MB_RES = 0.006`), Smooth, объединение с ушами.
* **Уши** — отдельные «раковины» (bmesh, параболический профиль + вогнутая внутренняя
  поверхность), внутренняя сторона — свой материал, поверх короткая светлая шерсть.
* **Глаза** — сферический глаз + аналитические «капы» радужки и зрачка (эллиптическая граница
  на сфере, строится по сетке — без «лестницы»), роговица (transmission 1.0, IOR 1.376),
  веко — тор, впаянный в кожу, поэтому оброс шерстью.
* **Радужка** — процедурный шейдер: радиальный градиент от янтарного центра к тёмному
  лимбу + noise-волокна.
* **Шерсть** — 9 particle-систем по зонам (тело/голова/уши/морда/лапы/живот/«шубка»/грудь/
  внутреннее ухо), ~680 тыс. волосков итого, у каждой зоны своя длина, густота, кол-во детей.
  Волосы-шейдер: почти чёрные у корня → тёплый коричневый блик на кончике (Hair Info).
* **Усы** — кривые (bezier, taper по радиусу), корни «вкопаны» в поверхность.
* **Нос** — чёрная кожа (base color ≈ 0.012, coat 0.35) — блик остаётся, оранжевого нет.
* **Уши** — высота 0.057 / полуширина 0.026 (уменьшены), шерсть на черепе 0.0074 м,
  чтобы силуэт ушей не «зарастал».
* **Свет** — 5 area-ламп (key/fill/два rim/glint для блика в глазу), тёмный «студийный» мир,
  пол с низким альбедо; AgX Medium High Contrast.

## Грабли Blender 5.2 (проверено на практике)
* `ParticleSettings.normal_factor` **перезаписывает** `hair_length` (length = 4·value) — не трогать.
* `tangent_factor` добавляется к волосу **в метрах** (0.42 → волос 1.7 м).
* `roughness_endpoint` — тоже в метрах: 0.3 превращает кота в шар из шерсти диаметром ~0.9 м.
* В `ParticleSettings` **удалены** `density_vertex_group`, `length_vertex_group`, `child_nbr`
  → плотность/длину по зонам пришлось делать через отдельные объекты-эмиттеры с вырезанными
  фейсами (зональная разбивка меша).
* `mesh.materials.clear()` сбрасывает `material_index` всех полигонов в 0 → слоты надо
  переписывать по месту и удалять хвостовые через `pop()`.
* Материал прядей берётся из **слота 0** объекта-эмиттера, поэтому `FurHair` = слот 0,
  кожа = 1, внутреннее ухо = 2.

## MCP-мост (чтобы рулить Blender напрямую)
```bash
# HTTP-режим сервера (stdio-серверы шлюз pi не принимает)
cd /Users/edm/blender_mcp/mcp && uv run blender-mcp --transport http --host 127.0.0.1 --port 8000
```
Затем в pi: `mcp install http://127.0.0.1:8000/ server=blender`.
Аддон Blender должен быть запущен и подключён (порт 9876).
